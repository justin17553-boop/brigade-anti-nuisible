Vos créneaux de rendez-vous

Touchez une case (créneaux d'une heure) pour la basculer entre Disponible (verte, réservable par les clients) et Indisponible (rouge, affichée « Pris »). Sous chaque date, les boutons matin, après-midi et journée basculent tout le groupe d'un coup. Puis Enregistrer : le site se met à jour en quelques minutes.

Page privée — elle n'apparaît dans aucun menu du site. Gardez son adresse pour vous. Les clients, eux, ne voient que le tableau de la page « Prendre rendez-vous ».

Première utilisation sur cet appareil

Pour que cette page puisse publier vos choix, collez ici votre jeton GitHub (créé une seule fois — voir le mode d'emploi transmis par Claude). Il reste enregistré uniquement dans ce navigateur.

Bon à savoir : les journées passées se nettoient toutes seules à l'enregistrement. Un créneau réservé en mode test sur un appareil (page demandes.html) ne bloque que cet appareil : ici, vous gérez ce que tout le monde voit.
