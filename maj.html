Installer une mise à jour

Quand Claude vous transmet un fichier de mise à jour (maj-….json), déposez-le ci-dessous puis touchez « Installer ». C'est tout : le site se met à jour en quelques minutes, sans clé à recopier.

Première utilisation sur cet appareil

Collez votre jeton GitHub une seule fois — le même que sur la page de gestion des créneaux. Il reste enregistré uniquement dans ce navigateur.

Déposez ici le fichier de mise à jour (ou touchez cette zone pour le choisir)

    Bon à savoir : cette page n'apparaît dans aucun menu — gardez son adresse pour vous. Elle n'installe que des fichiers du site (pages, styles, images) ; en cas de coupure, redéposez le fichier et recommencez, rien ne se casse.
